# 📊 Análisis de Ventas con Excel

Este proyecto es un análisis estratégico de ventas realizado en Excel, con el objetivo de identificar oportunidades de optimización y crecimiento a través de datos concretos.  
Se trabajaron variables como la estacionalidad, el comportamiento del cliente, la logística de envíos, la rentabilidad por segmento, geografía y los productos más vendidos.
